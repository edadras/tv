# LanCast — پخش فیلم از گوشی روی تلویزیون

<div dir="rtl">

یک اپ فلاتری که هم روی **گوشی اندروید** نصب می‌شود و هم روی **تلویزیون اندرویدی**.
فیلم را روی گوشی انتخاب می‌کنید و روی تلویزیون پخش می‌شود — با زیرنویس، جلو و عقب بردن،
مکث، و تنظیم دقیق همگام‌سازی زیرنویس. همه‌چیز روی وای‌فای خانه انجام می‌شود؛
نه اینترنتی لازم است، نه اکانتی، نه سروری بیرون از خانه.

اگر نخواهید چیزی روی تلویزیون نصب کنید هم مشکلی نیست: اپِ گوشی یک آدرس می‌دهد که
در **مرورگر تلویزیون** باز می‌کنید و فیلم همان‌جا پخش می‌شود.

## چطور کار می‌کند

فیلم هیچ‌جا کپی نمی‌شود. گوشی یک وب‌سرور کوچک روی خودش بالا می‌آورد و فایل اصلی را
تکه‌تکه (HTTP Range) برای تلویزیون می‌فرستد؛ برای همین پخش بلافاصله شروع می‌شود و
جلو و عقب بردن هم فوری است، حتی برای فیلم چندگیگابایتی.

```
┌─────────────────┐                          ┌──────────────────────┐
│      گوشی       │   HTTP + WebSocket       │      تلویزیون        │
│                 │ ───────────────────────► │                      │
│ • انتخاب فیلم   │   /media/…  ویدیو        │ الف) اپ تلویزیون     │
│ • وب‌سرور       │   /sub/….vtt زیرنویس      │ ب) مرورگر تلویزیون   │
│ • ریموت کنترل   │   /ws       فرمان‌ها       │                      │
│                 │ ◄─────────────────────── │  وضعیت پخش           │
└─────────────────┘                          └──────────────────────┘
```

هر دو گیرنده (اپ تلویزیون و مرورگر) دقیقاً یک پروتکل را می‌فهمند، پس ریموتِ گوشی
برای هر دو یکسان کار می‌کند.

## راه‌اندازی

### ۱) نصب روی گوشی

فایل `app-release.apk` را روی گوشی نصب کنید. بار اول اپ اجازه‌ی دسترسی به فایل‌ها
می‌خواهد — این اجازه لازم است تا فیلم بدون کپی‌شدن و با سرعت کامل پخش شود.

### ۲) تلویزیون — یکی از این دو راه

**بدون نصب (مرورگر تلویزیون):**
در اپ گوشی روی آیکن QR بزنید. یک آدرس مثل `192.168.1.5:8787` می‌بینید.
همان را در مرورگر تلویزیون تایپ کنید، یک بار دکمه‌ی «شروع» را بزنید، تمام.
بعد از آن همه‌چیز با گوشی کنترل می‌شود.

**با نصب (اپ تلویزیون):**
در همان صفحه‌ی مرورگر، «دانلود فایل نصبی» را بزنید — همان APK از روی گوشی دانلود و
روی تلویزیون نصب می‌شود. کابل و فلش و اپ انتقال فایل لازم نیست.
بعد از نصب، اپ تلویزیون خودش گوشی را در شبکه پیدا می‌کند.

> اپ خودش تشخیص می‌دهد روی گوشی است یا تلویزیون. اگر اشتباه تشخیص داد،
> از همان صفحه می‌توانید نقشِ دستگاه را دستی عوض کنید.

## امکانات

- **انتخاب فیلم** از حافظه‌ی گوشی، با مرورگر فایل داخلی و میان‌بر پوشه‌های پرکاربرد
- **زیرنویس**: فایل‌های کنار فیلم خودکار پیدا و اضافه می‌شوند (از جمله پوشه‌ی `Subs`)
- **فرمت‌های زیرنویس**: SRT، WebVTT، ASS/SSA
- **کدپیج**: زیرنویس‌های فارسیِ Windows-1256 خودکار تشخیص و درست خوانده می‌شوند
  (و «ي/ك» عربی به «ی/ک» فارسی تبدیل می‌شود)
- **همگام‌سازی زیرنویس**: پله‌های ۰٫۱ / ۰٫۵ / ۱ ثانیه، زنده و بدون توقف پخش.
  مقدارِ تنظیم‌شده برای هر فیلم ذخیره می‌شود
- **ظاهر زیرنویس**: اندازه، رنگ، تیرگی پس‌زمینه، فاصله از پایین، حاشیه، ضخامت
- **کنترل پخش**: پخش/مکث/توقف، ۱۰ و ۳۰ ثانیه جلو و عقب، نوار جابه‌جایی، صدا،
  سرعت پخش (۰٫۷۵ تا ۲ برابر)، اندازه‌ی تصویر (اصلی/پرکردن/کشیده)
- **ادامه از همان‌جا**: جای هر فیلم ذخیره می‌شود
- **پیداکردن خودکار** گوشی و تلویزیون در شبکه (و ورود دستی آدرس، اگر شبکه اجازه نداد)
- **ریموت تلویزیون**: چپ/راست جلو و عقب، OK پخش و مکث، بالا/پایین تنظیم زیرنویس
- **فونت فارسی** همراه اپ است، پس روی تلویزیون‌هایی که فونت فارسی ندارند هم درست
  نمایش داده می‌شود — حتی در مرورگر تلویزیون

## چیزهایی که خوب است بدانید

- گوشی و تلویزیون باید روی **یک شبکه** باشند. اگر روتر «جداسازی کاربران»
  (AP/Client Isolation) روشن دارد، باید خاموش شود.
- **فرمت‌ها**: اپ تلویزیون از ExoPlayer استفاده می‌کند و MP4/MKV با H.264 یا HEVC را
  به‌خوبی پخش می‌کند. مرورگر تلویزیون محدودتر است (عمدتاً MP4/H.264 و WebM)؛
  برای فایل‌های سنگین‌تر یا MKV، نسخه‌ی نصبی روی تلویزیون نتیجه‌ی بهتری می‌دهد.
- زیرنویس‌های **داخل** فایل MKV خوانده نمی‌شوند؛ زیرنویس باید فایل جدا باشد.
- سرور فقط تا وقتی اپ باز است بالاست، و فقط روی شبکه‌ی محلی گوش می‌دهد.

## ساخت از روی سورس

```bash
flutter pub get
flutter test                 # پارسر زیرنویس، پروتکل، و سرور واقعی روی سوکت
flutter build apk --release  # خروجی: build/app/outputs/flutter-apk/app-release.apk
```

خروجی یک APK همه‌کاره است که هم روی گوشی و هم روی تلویزیون نصب می‌شود.
برای فایل‌های کوچک‌تر (هر معماری جدا) از `flutter build apk --split-per-abi` استفاده کنید.

نسخه‌ی release با کلید debug امضا می‌شود تا نصب دستی و به‌روزرسانی روی نسخه‌ی قبلی
ساده باشد. اگر کلید خودتان را دارید، در `android/app/build.gradle.kts` جایگزین کنید.

### ابزارها

```bash
# اجرای پخش‌کننده‌ی مرورگری روی کامپیوتر، بدون گوشی و تلویزیون:
dart run tool/dev_server.dart <video.mp4> <subtitle.srt>
# بعد http://localhost:8787 را در مرورگر باز کنید.
# فرمان‌ها را می‌شود روی stdin فرستاد، مثلاً: {"do":"load"}

# ساخت تصویر از صفحه‌های اپ برای بررسی ظاهر:
flutter test test/design_preview_test.dart --tags preview --update-goldens
# تصویرها در test/preview/ ساخته می‌شوند.
```

## Structure (English)

| Path | What lives there |
|---|---|
| `lib/model/protocol.dart` | The JSON protocol both receivers speak |
| `lib/net/host_server.dart` | Phone side: HTTP range streaming + WebSocket hub |
| `lib/net/web_assets.dart` | The single-page browser player served to the TV |
| `lib/net/receiver_link.dart` | TV side: auto-reconnecting control channel |
| `lib/net/discovery.dart` | UDP beacon so the two halves find each other |
| `lib/subs/` | Subtitle parsing (SRT/VTT/ASS) and rendering |
| `lib/core/text_codec.dart` | Encoding sniffing — CP1256/CP1252/UTF-8/UTF-16 |
| `lib/state/` | `SenderController` (phone) and `ReceiverController` (TV) |
| `lib/ui/` | Navy-glass UI, split into `mobile/`, `tv/` and shared `common/` |
| `tool/dev_server.dart` | Runs the real server from a desktop, for testing the web player |

`model/`, `net/`, `subs/` and `media/` are plain Dart with no Flutter imports, so
they run and test outside a device.

Subtitles are parsed and drawn by the app rather than handed to the platform
player. That is what makes the sync offset exact: shifting the cue lookup time
is the whole implementation, on the TV and in the browser alike.
